How to mark

  1. Click-drag a tight box around each visible crack.
  2. Trace close to the crack — the box becomes the crop that gets edge-detected, so a loose box picks up extra background.
  3. One box per crack segment; split broken cracks into separate boxes.
  4. Made a mistake? Use Undo or click × on a row.
