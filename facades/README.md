# facades/

Per-facade pipeline output. Not tracked in git — generated by running the
pipeline (see the root README's "실행" section), not source code.

## Layout (CLAUDE.local.md #28)

```
facades/
  <facade_id>/
    output/
      <facade_id>_analysis.tif           # homography-chain, minimal blend (crack detail preserved)
      <facade_id>_visual.tif             # homography-chain, presentable blend
      <facade_id>_analysis_colmap.tif    # COLMAP-rectified (only when a building footprint + COLMAP fallback ran)
      <facade_id>_visual_colmap.tif
      <facade_id>_observed_mask.tif
      <facade_id>_quality_report.json
      <facade_id>_quality_report_colmap.json
      <facade_id>_colmap_report.json
      <facade_id>_failed_pairs.json
      <facade_id>_source_images.json
```

Regenerate by running the pipeline against a folder of DJI images — see the
root README.
