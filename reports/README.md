# reports/

Aggregated Complex/Building PDF reports (`{complex}[_{building}]_종합보고서.pdf`),
generated by `tools/generate_report.py building ...` (see
`src/report/pdf_report.py`). Not tracked in git — regenerable output, not
source code, and may contain customer-identifying data.

Per-facade reports (`{facade_id}_report.pdf`) live next to that facade's own
output instead (`facades/<facade_id>/output/`), not here.
